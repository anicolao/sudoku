# Photo import regression corpus

Open [review.html](review.html) locally to compare each original image with its proposed golden master. The page links to the full-resolution images and playable puzzles. These expectations are explicit, not generated by recognition or by solving the puzzle.

This branch is a work in progress: the full corpus is not yet passing. The suite deliberately keeps recognition mismatches red rather than updating expectations to whatever OCR returns. In particular, the yellow annotation in `12paper.jpeg` obscures clue strokes, `22handwritten.jpeg` mixes handwritten digits with crossed-out candidates, and the current transcription of `21forward.webp` has multiple solutions even with its three large handwritten placements. That last case needs an explicit decision about reviewing non-unique puzzles; this branch does not relax the application's uniqueness requirement.

Run `npm run test:e2e:photos` to import every image through the real photo-import UI. A pass requires an exact board match, a validated unique solution, and successfully starting that same puzzle. Each example uses fresh browser storage. Failures do not prevent the remaining examples from running.

The Playwright report includes a portable `photo-import-review.html` attachment with the original, golden master, actual straightened grid, and actual recognized board. Differences are shaded red. This attachment embeds its images, so it also works after downloading the CI report.

`goldens.json` is the reviewable source of expectations. Notes and visibly distinct work are excluded where possible; full-size work indistinguishable from clues may remain. Uncertain readings may be blanked only when the resulting visible clues still uniquely identify the puzzle. The recognizer never fills blanks from a computed solution.

When adding a photo, transcribe and review its expected board, add it to `goldens.json`, and run `npm run photos:review` to regenerate the comparison page. The suite fails if an image lacks an expectation. There is deliberately no automatic golden-update command.
